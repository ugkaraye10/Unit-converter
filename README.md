# CE-LAB UTILITY v2.0 ⬡

A high-performance, mobile-responsive web toolkit designed for **Computer Engineering** students and lab attendants at **Ahmadu Bello University**.

## ⚡ Features
- **Logic Gate Converter:** Instant conversion between Binary (8/16-bit), Hex, Octal, and Decimal.
- **Ohm's Law Calculator:** Solves for Voltage, Current, or Resistance with real-time Power (Watts) calculation.
- **Resistor Decoder:** Visual 4-band color code decoder with tolerance range calculation.
- **Data Scaler:** Quick conversion between storage units (Bits, Bytes, MB, GB, etc.).

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+).
- **Design:** CRT-style "Terminal" aesthetic with mobile-first responsiveness.
- **Performance:** Zero-latency client-side processing (no backend required).
